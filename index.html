DERYCODE SECSCAN · v2.0

Test your software before hackers do

A defensive vulnerability scanner for websites you own. One command checks for exposed files, open admin panels, missing security headers and information leaks — the first things an attacker looks for.

python3 secscan.py https://your-site.com

Pure Python — no installation, no dependencies. Passive checks only, nothing is exploited or modified.

What it finds

🔴 Exposed secrets.git folders, .env files, SQL dumps, phpinfo pages — the fastest way attackers steal your code and credentials.
🟠 Open admin panelsChecks /admin, /dashboard, /panel and more, and whether they actually demand a login before showing anything.
🟡 Security headersHSTS, CSP, clickjacking and MIME-sniffing protection — the headers that stop XSS and framing attacks.
🔵 Information leaksDirectory listings, server versions, dependency files and open API endpoints returning JSON to anyone.

Graded like an exam

Critical — fix today

Exposed secrets, database files, passwords travelling over plain HTTP.

High — fix this week

Unprotected panels, cookie theft paths, CORS misconfigurations.

Medium — plan the fix

CSP, clickjacking protection, mixed content.

Low — hardening

Version disclosure and minor header hygiene.

Built-in safety

SecScan sends only safe GET requests and passive checks — no attack payloads, no credential guessing, no changes to your site. Use it only on systems you own or have written permission to test. Non-zero exit code on findings means it fits straight into a CI pipeline.
